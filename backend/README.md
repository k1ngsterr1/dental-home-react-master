# Dental Home Backend

Backend сервер для обработки заявок с сайта Dental Home.

## Возможности

- 📧 Отправка заявок на вакансии на email
- 📎 Поддержка прикрепления резюме (PDF, DOC, DOCX, TXT)
- 🛡️ Защита от спама и лимиты запросов
- 🔒 Безопасность с помощью Helmet
- ✅ Валидация данных
- 📨 Автоматические письма-подтверждения

## Установка

1. Установите зависимости:

```bash
cd backend
npm install
```

2. Запустите сервер:

```bash
# Продакшн
npm start

# Разработка (с автоперезагрузкой)
npm run dev
```

## API Endpoints

### POST /api/apply

Отправка заявки на вакансию

**Body (multipart/form-data):**

```json
{
  "name": "Имя кандидата",
  "phone": "+7 (999) 123-45-67",
  "email": "candidate@example.com",
  "message": "Сопроводительное письмо",
  "vacancy": "Название вакансии",
  "resume": "файл резюме (опционально)"
}
```

### POST /api/contact

Общая контактная форма

**Body (JSON):**

```json
{
  "name": "Имя",
  "phone": "+7 (999) 123-45-67",
  "email": "user@example.com",
  "message": "Сообщение",
  "service": "Название услуги"
}
```

### GET /api/health

Проверка работоспособности сервера

## Безопасность

- Rate limiting: 10 запросов в 15 минут с одного IP
- CORS настроен для разрешенных доменов
- Валидация всех входных данных
- Защита от XSS и других атак с помощью Helmet
- Ограничение размера файлов: 5MB

## Логирование

Все заявки логируются в консоль с указанием времени и данных отправителя.

## Структура писем

Письма отправляются в HTML формате с красивым оформлением и включают:

- Все данные заявки
- Время отправки
- Прикрепленные файлы (для вакансий)
- Автоматические уведомления для кандидатов
